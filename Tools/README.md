This directory references practical tools built for cybersecurity workflows,
automation, privacy, and technical experimentation.

## Available tools

### [PDF Merger](https://github.com/jesscybersec/PDFMerger)

A local-first Streamlit utility for merging, reordering, bookmarking, and
OCR-processing PDF collections without sending documents to a cloud service.

PDF Merger is maintained in its own standalone repository for simpler
installation, versioning, and releases.

### [Neon Scraper](https://github.com/jesscybersec/Neon-Scraper)

A cyberpunk-flavoured, local-first passive exposure monitor for approved public
web sources, with CLI and localhost web UI, SQLite storage, Markdown reports,
request audit logs, analyst review workflow, and an experimental allowlisted Tor
module disabled by default.

Neon Scraper is maintained in its own standalone repository so it can evolve as
a focused tool while CyberJess-Lab stays clean and navigable.
